### Cómo trabajo con IA

- Defino qué se construye y dejo las reglas del proyecto escritas para el agente (`CLAUDE.md`, `AGENTS.md`).
- Planifico antes de programar: reviso cada plan y cada migración de la base de datos antes de aprobarla.
- Una rama por tarea; nada llega a `main` sin mi revisión.
- Tests automáticos, workflows de GitHub Actions y prueba final en un móvil real.
